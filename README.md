# DobleFoco — el método

[DobleFoco](https://doblefoco.co) ubica a los medios colombianos en un mapa según
su línea editorial y su factualidad. Este repositorio guarda **por qué cada medio
está donde está**, para que cualquiera pueda auditarlo.

El código del sitio no está aquí: es privado. Lo que sí está es todo lo que hace
falta para discutir una clasificación.

| Qué | Dónde |
|---|---|
| Las reglas con las que se clasifica | [`PROTOCOLO_JUICIO_EDITORIAL.md`](PROTOCOLO_JUICIO_EDITORIAL.md) |
| Cada decisión, con su fecha y su motivo | [`DECISIONES.md`](DECISIONES.md) |
| La ficha de cada medio: propiedad, contratación pública, evidencia y valor | [`fichas/`](fichas/) |
| Las revisiones externas, con la respuesta literal del revisor y su resolución | [`revision-externa/respuestas/`](revision-externa/respuestas/) |
| Los barridos de evidencia editorial histórica | [`revision-externa/barridos/`](revision-externa/barridos/) |
| El encargo que recibe el revisor y el plan de cada ciclo | [`revision-externa/`](revision-externa/) |
| El catálogo y el modelo, tal como los usa el sitio | [`src/docs/`](src/docs/) |

## Si crees que un medio está mal ubicado

Abre un *issue* con la evidencia: un enlace, la fecha y la cita literal. El
protocolo explica qué cuenta como evidencia y qué no (la «regla del presente»,
el «polo fijo»). Las objeciones con fuente se revisan en el siguiente ciclo.

## Datos personales

Los teléfonos y correos de personas se omiten al publicar. Nunca se escriben
cédulas ni direcciones particulares (Ley 1581 de 2012).

## Uso

Todos los derechos reservados salvo que se indique otra cosa. Puedes leer,
enlazar y citar estos documentos para discutir o criticar la clasificación.
